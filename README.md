# 🐱 Купикот

Симулятор торгов за породистых котят. Угадай цену по фото!

## Описание

Купикот — это интерактивное веб-приложение, где пользователь угадывает цену породистых котят по фотографиям и описаниям. Каждый раунд состоит из 10 случайных объявлений, а по итогам игры пользователь получает одну из категорий "хозяина кота".

## Механика

- 10 случайных котят из базы объявлений
- Бегунок для выбора цены (от 0 до 200 000 ₽)
- Система баллов: от 5 до 100 за каждый раунд
- Итоговая категория зависит от набранных баллов

### Система баллов

| Отклонение от цены | Баллы |
|---|---|
| ≤ 5% | 100 |
| ≤ 10% | 80 |
| ≤ 15% | 60 |
| ≤ 25% | 40 |
| ≤ 40% | 20 |
| ≤ 60% | 10 |
| > 60% | 5 |

### Категории

| Баллы | Категория |
|---|---|
| 900-1000 | 👑 Кошачий Магнат |
| 750-899 | 🏆 Опытный Фелинолог |
| 600-749 | 🎓 Кото-Эксперт |
| 450-599 | 😺 Любитель Котиков |
| 300-449 | 🐱 Начинающий Котовладелец |
| 150-299 | 🐾 Котопутник |
| < 150 | 😸 Дворовый Кот |

## Технологии

- **React 19** + TypeScript
- **Vite** — сборка
- **Tailwind CSS 4** — стилизация
- Основной цвет: `#cc8a60`

## Запуск

```bash
# Установка зависимостей
npm install

# Разработка (hot reload)
npm run dev

# Сборка для продакшена
npm run build

# Превью собранной версии
npm run preview
```

## Деплой

Проект — статический SPA. После `npm run build` содержимое папки `dist/` можно разместить на любом хостинге:

- **Vercel**: `vercel deploy`
- **Netlify**: перетащить папку `dist/` или подключить репозиторий
- **GitHub Pages**: загрузить `dist/` в ветку `gh-pages`
- **Любой статический хостинг**: загрузить содержимое `dist/`

## Структура

```
src/
├── App.tsx          # Главный компонент (роутинг экранов)
├── data/
│   └── cats.ts      # База котят (60 объявлений)
├── index.css        # Глобальные стили
└── main.tsx         # Точка входа
```

## Security Headers

В `index.html` настроены:
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Referrer-Policy: strict-origin-when-cross-origin`
